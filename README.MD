# Sistema de Reservas de Hotel

Trabalho avaliativo de programação em Python: sistema de reservas de hotel
no terminal, combina os paradigmas procedural (`main.py`)e orientado a
objetos (`models.py`), com dados salvos em JSON (`dados.py`).

## Execução

Precisa Python 3.8 ou superior. Não há uso de bibliotecas.

```bash
python main.py
```

Os dados são salvos em `dados/`.
